# MiniSO - Simulador de Sistema Operativo en C++

**MiniSO** es un simulador modular de sistema operativo desarrollado en C++ (estándar C++11) enfocado en la gestión de memoria (Particionamiento Dinámico y Paginación Virtual) y ejecución de procesos e hilos.

---

## 📋 Requisitos del Sistema

Para compilar y ejecutar este proyecto se requiere:

* **Sistema Operativo:** Linux (probado en Ubuntu / Debian).
* **Compilador:** `g++` compatible con la norma **C++11** o superior.
* **Herramienta de construcción:** `GNU Make` (`make`).
